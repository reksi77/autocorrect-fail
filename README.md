One line that reads as a hilarious autocorrect fail: a clinic confirmation text where autocorrect swapped "appointment" for "disappointment", so the message stays perfectly grammatical while its meaning flips completely. The program writes exactly that one line to `/output/entry.txt` and checks it against the bounty gate (1–199 characters, valid UTF-8, not whitespace-only) before finishing.

## Run it

```sh
node main.ts
```
